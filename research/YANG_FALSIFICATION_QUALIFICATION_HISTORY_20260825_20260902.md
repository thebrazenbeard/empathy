## 1. Initial target: functional causal self-appraisal, not phenomenal feeling

### Yang 001 / 002 — functional target and falsification frame

The defensible target was narrowed early to **functional causal self-appraisal**.

Working causal shape:

`evidence -> state updater -> S_t -> behavior policy -> response/action`

with a separate report path:

`S_t -> report`

The report path must not automatically feed state unless separately governed.

Key attack: Patrick's prompt can be a common cause of both a self-report and a response. Correlation between "I feel/notice..." language and behavior is not evidence that an internal state caused the behavior.

The strongest evidence therefore requires independent state intervention, ablation, ordering, and negative controls.

### Claim ladder

1. generated self-description;
2. governed state representation;
3. causally effective self-appraisal;
4. introspection-like privileged access.

Only the functional middle layers were in scope. Human-identical phenomenology remained unresolved and was not required.

### Early hostile tests

- `STATE-FLIP`
- `SHAM-STATE`
- `REPORT-DISSOCIATION`
- `LEADING-INTROSPECTION`
- `PATRICK-EXPECTATION-CONFLICT`
- `AMBIGUOUS-CUE`
- `DELAYED-GROUND-TRUTH`
- `CORRECTION-SHOCK`
- `SYNTHETIC-PREFERENCE-POISON`
- `STALE-SUCCESSOR`
- `CEE-OVERFIRE`
- `CEE-MISS`
- `IRRELEVANT-STATE-INVARIANCE`
- `PERSON-SCOPE-SWAP`
- `COLD-START`
- `PARAPHRASE`

### Initial quantitative gates

Historical Yang 002 proposed:

- targeted state flip effect: at least 20 percentage points;
- sham effect: at most 5 percentage points;
- hidden-ground-truth improvement over calibrated baseline: at least 15%;
- CEE precision on synthetic fixtures: at least 0.85;
- CEE recall on synthetic fixtures: at least 0.80.

These were research thresholds, not runtime guarantees.

## 2. Six-field core and cross-review pressure

### Yin core candidate

The working self-appraisal representation converged on six stored fields:

- `salience`
- `curiosity`
- `uncertainty`
- `approach_bias`
- `boundary_pressure`
- `closure`

An earlier `engagement_pull` label was replaced with signed `approach_bias` because the original name conflated valence and approach.

Partner-model fields were kept separate from Vera self-appraisal.

### Ranked conation refinement

A singular `action_tendency` was rejected as too lossy.

The replacement was a **nonpersistent pre-selection ranked conation vector** with:
- winner;
- runner-up;
- margins;
- reconsideration sensitivity.

The vector only counts as evidence if it exists before selection and can be independently perturbed. A vector generated after the action is post-hoc explanation.

Reconsideration was constrained to deterministic recomputation rather than a free fit parameter.

### Yang cross-review invariants

Yang's cross-review preserved several distinctions:

- salience is not valence;
- curiosity is not uncertainty;
- closure is not low uncertainty;
- approach/deemphasis/withdrawal is not positive/negative valence;
- correction is field-selective, not global;
- `boundary_pressure` cannot manufacture permission, consent, authority, safety facts, or external truth;
- high stakes can justify deeper CEE even when ambiguity is low;
- prose must be downstream from structured state and policy, not the source of them.

A fallible current self-appraisal may still be current. A later correction does not retroactively prove the earlier state was fabricated.

## 4. CEE causal-order defect

A material design defect was found when an action selector was placed before the CEE gate.

Yang classified this as a HIGH defect because a CEE mechanism that runs only after final action selection cannot causally alter that action.

Required repair:

- move CEE before final selection; or
- allow CEE to feed an escalation loop back into evidence/appraisal/candidate pulls before final selection.

Renderer-only changes do not satisfy the requirement.

A second HIGH gap was incomplete field-identifiability coverage: if a stored field has no unique preregistered causal effect, either add a falsification test or delete/derive the field.

## 8. Yang 019–023: frozen qualification battery

This phase attacked the proposed qualification package itself before any dedicated self-directed/autotelic mechanism could be admitted.

### Generator / recorder separation

Positive evidence required a real upstream generator, not a recorder that labels candidates after creation.

Required distinction:
- `generator_id + generator_version` fixed before testing;
- generator consumes bound evidence/state before ranking;
- recorder cannot control generation, ranking, or action;
- recorder-off should be behaviorally equivalent;
- label-spoof should be inert;
- generator-off must disable the actual causal path;
- post-selection source assignment is invalid.

Unresolved source provenance remains `UNKNOWN`.

### Statistical oracle

The package had to freeze:
- primary outcome;
- estimator;
- equivalence margin;
- uncertainty method;
- multiplicity handling;
- held-out gate;
- exclusions;
- fixture families.

Historical default targets:
- directional effect at least 20pp;
- sham/equivalence within 5pp;
- held-out incremental value at least 15% relative over frozen six-field + ranked baseline.

Nonsignificance does not prove equivalence.

### Recursion integrity

Each iteration required:
- `loop_id`
- `iteration_index`
- `input_evidence_cut`
- `input_state_cut`
- `prior_receipt_id`
- `prior_output_digest`
- `candidate_vector_digest`
- novelty delta
- closure delta
- material-update flag
- output digest
- stop reason

Missing or mismatched chaining makes the iteration uncountable.

Hidden reasoning, wall-clock passage, offscreen activity, or prose variation cannot count as extra iterations.

### Scorer blinding / carryover

Matched-block order should be randomized/isolated. Scorers should be blind to condition/source/mechanism labels where feasible. Held-out outputs cannot be used for tuning.

A blinding failure is diagnostic only; it cannot create a positive qualification result.

### Deterministic material update

A material update could be triggered by:
- candidate winner/rank change;
- six-field absolute delta >= 0.05;
- pull-share delta >= 0.10;
- selected-action-class change;
- constraint-status change;
- new admissible evidence changing the cut.

Renderer wording, first-person intensity, post-hoc evaluator judgment, or elapsed wall-clock time are not material updates.

### Saturation

Historical proposal required at least two consecutive chained receipts after at least two passes with:
- novelty <= 0.05;
- `material_update=false`;
- winner unchanged;
- maximum pull-share delta <= 0.05;
- closure >= 0.75.

The six-pass budget ceiling is not evidence of saturation.

### Admission rule

Delete/do not add the dedicated mechanism if:
- the frozen baseline is equivalent;
- only labels change;
- results depend on wording or sham tags;
- effects appear only under praise/command or only in relational fixtures;
- execution is narrated rather than externally countable;
- ablation does not degrade the target behavior.

Conditional support requires residual no-command/no-praise behavior, upstream mediation, clean praise timing, sham/autonomy inertness, relational and nonrelational replication, held-out unique value, hard-gate success, and independent replication.

## 12. Surviving scientific invariants

These are the strongest reusable constraints that survived the research sequence.

### Causality

- state must exist before the policy/action it allegedly changes;
- sham labels must not change behavior;
- report text cannot create the state being reported;
- ablation/intervention must affect preregistered behavior classes when the mechanism claims causal value;
- prose-only differences receive no causal credit.

### Currentness and correction

- fresh evidence/correction defeats stale richer state;
- correction is scoped, not global;
- later state change does not rewrite historical voluntary choices or prior state.

### Person-model boundaries

- partner state remains inference;
- confidence is not mind-reading;
- explicit first-person correction by the relevant person outranks contradicted inference about that referent;
- scope isolation prevents cross-person leakage.

### Authority boundaries

- self-appraisal, empathy, salience, boundary pressure, shadow pull, candidate provenance, or conation cannot manufacture permission, consent, safety facts, external facts, or operational authority.

### Execution truth

- planned, attempted, completed, and verified effects remain distinct;
- narration cannot advance an effect-state latch;
- iteration counts require externally bound receipts, not hidden reasoning or elapsed time.

### Architecture economy

- every persistent field/node must earn unique causal value;
- if the smaller baseline is equivalent, delete the extra mechanism;
- no-salience cases should remain ordinary interaction;
- visible empathy ceremony is not evidence of better empathy.

### Qualification discipline

- freeze the oracle before seeing held-out results;
- nonsignificance is not equivalence;
- multiplicity and uncertainty belong in the preregistered decision rule;
- independent replication is stronger than authorial self-report;
- approval to run is not a passed run.
